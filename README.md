# BioDex

BioDex is an Android-first, offline plant-collector MVP built with Kotlin, Jetpack Compose, CameraX, and the official Imageomics BioCLIP 2.5 ViT-H/14 image encoder. Capture a plant photo, find its closest match in a 4,271-species field guide, generate a field card, save it locally, and share the PNG.

## Run

### Prepare the official model

The app uses the official checkpoint, not the smaller distilled student. The upstream OpenCLIP/PyTorch checkpoint is about **3.94 GB**. Before building the app:

1. Install Python 3.13 and create the project environment with `py -3.13 -m venv .venv`.
2. Install the model-export dependencies: `.venv\Scripts\python.exe -m pip install -r scripts\requirements-bioclip-export.txt`.
3. Run `.venv\Scripts\python.exe scripts\export-bioclip-25-onnx.py`.

The exporter verifies the existing 4,271-label embedding table against its published SHA-256 (the model author identifies it as the teacher's text-embedding space), downloads the checkpoint at a pinned Hugging Face revision, exports an FP16 ONNX image encoder, and verifies its output against OpenCLIP and ONNX Runtime. The current exported image encoder is **1.26 GB**. It is stored in the app assets and included in the APK. The downloaded source checkpoint is cached under the current user's `.cache\biodex` directory.

### From VS Code on Windows

1. Install Android SDK Platform 35 and Android SDK Build-Tools 35.0.0 in Android Studio's SDK Manager.
2. Use a higher-end Android 8.0+ phone with at least about **3 GB of free storage** and several GB of available RAM. The 12 GB Galaxy S24 Ultra is the current physical-device test target; smaller devices may run out of memory or be very slow.
3. Connect the phone with USB debugging enabled, or start an Android emulator with sufficient resources.
4. Open this folder in VS Code and run **Terminal > Run Task > Run BioDex on Android emulator**.
5. Grant camera access, capture a photo, and save the generated card.

The VS Code task builds and installs the device-ABI debug APK, then opens it on the connected device. If no device is connected, it starts the first configured AVD. It uses the Android Studio bundled JDK when available. The APK includes the 1.26 GB image encoder; the app also copies it into private storage on first inference, so install and first classification take noticeably longer than the earlier student-model build.

## What works in this MVP

- CameraX photo capture with runtime camera permission.
- Offline image inference using a bundled FP16 ONNX export of the official BioCLIP 2.5 ViT-H/14 image encoder.
- Best-match lookup across 4,271 plant species using text embeddings generated by the official model's text encoder.
- Generated PNG field cards saved with the collection in app-private storage.
- Collection grid and Android share sheet export.

## Important limitations

The encoder is BioCLIP 2.5 Huge, but the app's current candidate list remains limited to **4,271 plants**. It cannot identify animals or fungi, and species outside its list cannot be returned. The model card reports zero-shot benchmark scores and an improvement over BioCLIP 2; those benchmark results do not guarantee correctness for a particular photo or location. Field performance still needs testing on real photos from the intended region.

The displayed cosine similarity is **not a probability or calibrated confidence**. Identification is a suggestion, not a verified observation. Never use it to decide whether a plant is edible, poisonous, medicinal, or otherwise safe.

## Model source and license

- Official model: [Imageomics BioCLIP 2.5 ViT-H/14](https://huggingface.co/imageomics/bioclip-2.5-vith14), MIT licensed and listed in the [BioCLIP collection](https://huggingface.co/collections/imageomics/bioclip). The export pins revision `6e3d04e3d6522012c88181085c5ae666e14c45cd`.
- Generated app files: `bioclip_2_5_vith14_image_fp16.onnx`, `taxa_table.npy`, `taxa_labels.json`, and `model-info.json` under `app/src/main/assets/bioclip`. The model-info file records generated hashes and sizes; the large ONNX file is git-ignored and must be recreated with the exporter after a fresh checkout. See [NOTICE.md](./app/src/main/assets/bioclip/NOTICE.md) for attribution.
- Runtime: ONNX Runtime Android `1.24.2`.
- Image preprocessing follows the model configuration: RGB, resize and center crop to 224 — 224, then ImageNet-style CLIP channel normalization. The image encoder's normalized output is compared with official-model text embeddings made from `a photo of {scientific_name}.`

The training images belong to their respective photographers and are not bundled. See the linked model card for training data, evaluation caveats, attribution, and licensing details.

The PC needs internet access to download the model before building. Once installed, photos and cards stay in the app's private local files; inference is on-device, and the app does not request location, use network access, or upload images. Clearing app data removes the local collection and model cache.

## Gemma card notes (precomputed)

Common names and the short card detail for all 4,271 BioCLIP plant labels were generated offline with Gemma 4 (`gemma4:e4b` via Ollama) and are shipped as `app/src/main/assets/bioclip/species_notes.json`. No language model runs on the phone. To regenerate (resumable):

    ollama pull gemma4:e4b
    python tools\generate_notes.py gemma4:e4b

The text is AI-written and may contain inaccuracies (Gemma terms of use apply). Location (coarse, optional) is used only for the card footer and stays on the device. Photos with BioCLIP cosine similarity below 0.45 are rejected.

## UX, XP and missions

The UI follows the BioDex Figma Make design (splash, dashboard, camera, specimen card). Discoveries earn XP by rarity (duplicates 25 XP), 1,000 XP per level, a daily streak, a daily field mission with bonus XP and badges, and a field rank. Progress is stored locally (ProgressStore). Fonts DM Sans and DM Serif Display are bundled under the SIL OFL.
